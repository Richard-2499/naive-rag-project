     │   │   └─ 示例：类型过滤、格式校验
     │   └─ 否 ↓
     ├─ 结构化匹配？

     ├─ 需语义理解？
     │   ├─ 是 → LLM
     │   │   └─ 示例：因果推理、情感分析
     │   └─ 否 ↓
     └─ 可安全自动？

         │   └─ 示例：规则筛选候选 + LLM确认
         └─ 否 → 人工审查


5.
问题：总结的两个边界怎么判断？
答案：何时总结： - ✓ 样本量足够（定量>30，定性>10） - ✓ 规律已稳定（新模式=0，连续2轮） - ✓ 有实际用途（下次遇到可直接套用）
     何时不总结： - ✗ 样本量不足（偶然规律） - ✗ 规律未收敛（仍在快速变化） - ✗ 过度泛化（方法 vs 具体方案）

7.
问题：总结的反模式有哪些？
答案：反模式1: 总结代替思考
     反模式2: 追求完美总结
     反模式3: 只总结成功经验


8.
问题：总结的反模式2中的正确做法是什么？
答案：第一版：用1小时写核心要点（1页）
       → 够用即可，不追求完美

     第二版：使用过程中发现不足，补充（3页）
       → 基于实际需求演化

     第三版：跨项目复用，提炼通用部分（5页）
       → 稳定版本


9.
问题：总结的反模式的原则是什么？
答案： - 总结也要迭代（不要追求一次性完美）
      - 够用就好（过度总结 = 浪费计算资源）
      - 让Agent执行反馈（总结是否有用，实际效果说了算）
